# Sonic Vein Studio 社区 / Community

欢迎来到 Sonic Vein Studio 用户与开发者社区！这里用于 Bug 反馈、功能建议、使用问答与经验交流。**欢迎使用中文或英文发帖，无需同时提供两种语言；社区维护的说明和模板采用中英双语。**

Welcome to the Sonic Vein Studio user and developer community for bug reports, feature requests, Q&A and workflow discussions. **Post in Chinese or English; no bilingual translation is required from participants. Community-maintained guides and templates are bilingual.**

> **Sonic Vein Studio 是闭源产品。** 本仓库仅提供社区资料与反馈入口，不包含产品源码；本仓库的公开不授予产品源码、商标或其他产品资产的使用许可。

> **Sonic Vein Studio is closed source.** This repository contains only community materials and feedback tools, not product source code. Its public availability grants no license to the product source code, trademarks or other product assets.

## 参与社区 / Participate

- [报告 Bug / Report a bug](https://github.com/sonicvein/SonicVeinStudio-Community/issues/new/choose)：提交可复现的问题、崩溃或异常行为。Report reproducible issues, crashes or unexpected behavior.
- [功能建议 / Request a feature](https://github.com/sonicvein/SonicVeinStudio-Community/issues/new/choose)：描述使用场景、问题与预期体验。Describe your use case, problem and desired experience.
- [问答与交流 / Q&A and discussions](https://github.com/sonicvein/SonicVeinStudio-Community/discussions)：使用求助、工作流分享与开发者交流。Get help, share workflows and connect with developers.
- [已有反馈 / Existing issues](https://github.com/sonicvein/SonicVeinStudio-Community/issues)：提交前先搜索，已有问题可补充复现信息。Search before posting and add useful reproduction details to existing reports.

## 有效的 Bug 反馈 / Writing a useful bug report

请提供应用版本、操作系统及版本、运行方式（独立应用或插件）、宿主软件与版本（如适用）、复现步骤、预期行为和实际行为。音频问题请补充音频设备、采样率与缓冲区大小。可附已脱敏的截图或最小复现材料。每个 Issue 尽量只讨论一个问题。

Include the app version, operating system and version, standalone or plugin mode, host and version if applicable, reproduction steps, and expected versus actual behavior. For audio issues, include the audio device, sample rate and buffer size. Redacted screenshots or minimal reproduction materials help. Keep each issue focused on one problem.

## 隐私与安全 / Privacy and security

Issues、Discussions 和附件均公开可见。请勿上传许可证密钥、账号信息、访问令牌、个人路径、未公开源码或未经授权的工程、音频及其他素材；上传日志前请先检查并脱敏。

Issues, discussions and attachments are public. Do not upload license keys, account details, access tokens, personal file paths, private source code, or projects, audio and other materials you are not authorized to share. Review and redact logs before uploading.

安全漏洞、授权绕过或其他敏感问题，请勿公开提交细节。请通过 [tech@sonicvein.com](mailto:tech@sonicvein.com) 私下联系，在获得回复后再传递敏感复现材料。

Do not disclose vulnerabilities, licensing bypasses or other sensitive security details publicly. Contact [tech@sonicvein.com](mailto:tech@sonicvein.com) privately and wait for a reply before sharing sensitive reproduction materials.

## 社区约定 / Community guidelines

请友善、尊重他人，围绕具体问题提供信息；不发布骚扰、垃圾信息或无权分享的内容。维护者会按情况评估反馈，提交建议不代表实现或发布时间承诺。

Be kind, respectful and specific. Do not post harassment, spam or content you have no right to share. Maintainers assess feedback as appropriate; submitting a request does not guarantee implementation or a release date.
