# Sonic Vein Studio Community

欢迎来到 Sonic Vein Studio 用户与开发者社区！这里用于 Bug 反馈、功能建议、使用问答与经验交流。欢迎使用中文或 English。

> **Sonic Vein Studio 是闭源产品。** 本仓库仅提供社区资料与反馈入口，不包含产品源码；本仓库的公开不授予产品源码、商标或其他产品资产的使用许可。

## 参与社区

- [报告 Bug](https://github.com/sonicvein/SonicVeinStudio-Community/issues/new/choose)：提交可复现的问题、崩溃或异常行为。
- [提出功能建议](https://github.com/sonicvein/SonicVeinStudio-Community/issues/new/choose)：描述使用场景、希望解决的问题与预期体验。
- [问答与交流](https://github.com/sonicvein/SonicVeinStudio-Community/discussions)：使用求助、工作流分享与开发者交流。
- [查看已有反馈](https://github.com/sonicvein/SonicVeinStudio-Community/issues)：提交前请先搜索，已有问题可补充复现信息。

## 怎样写一份有效的 Bug 反馈

请提供应用版本、操作系统及版本、运行方式（独立应用或插件）、宿主软件与版本（如适用）、复现步骤、预期行为和实际行为。音频相关问题请补充音频设备、采样率与缓冲区大小。附上已脱敏的截图或最小复现材料会更有帮助。每个 Issue 尽量只讨论一个问题。

## 隐私与安全

这里的 Issues、Discussions 和附件均公开可见。请勿上传许可证密钥、账号信息、访问令牌、个人路径、未公开源码或未经授权的工程、音频及其他素材；上传日志前请先检查并脱敏。

安全漏洞、授权绕过或其他敏感问题，请勿公开提交细节。请通过 [tech@sonicvein.com](mailto:tech@sonicvein.com) 私下联系，并在获得回复后再传递敏感复现材料。

## 社区约定

请友善、尊重他人，围绕具体问题提供信息；不发布骚扰、垃圾信息或无权分享的内容。反馈会由维护者按情况评估，提交建议不代表承诺实现或发布时间。
